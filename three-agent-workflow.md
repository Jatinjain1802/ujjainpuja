# Three-Agent Design Workflow

This project now includes a simple workflow concept for the requested three-agent process:

1. **Agent 1 – Design Analyst**
   - Inspects the reference website and extracts the visual style, typography, colors, spacing, and page structure.
   - Creates a prompt or implementation guidance for the builder.

2. **Agent 2 – React Builder**
   - Takes the prompt from Agent 1 and converts the design into reusable React components and updated styles.
   - Implements the site layout, hero section, services, gallery, contact, and navigation.

3. **Agent 3 – Review & Feedback**
   - Reviews the built pages and existing styling.
   - Provides feedback to Agent 1 and Agent 2 to refine the design fidelity and user experience.

The current code changes focus on aligning the React app with the reference site's warm brand, hero presentation, CTA styling, and structured content blocks. The workflow document is included to capture the three-agent concept in the repository.
